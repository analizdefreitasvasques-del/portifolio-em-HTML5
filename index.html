Sistema-Acadêmico

O Sistema de Gestão Acadêmica permite o cadastramento, validação e consulta de alunos e professores em uma instituição ensino. O projeto foi estruturado com foco em boas práticas de POO, encapsulamento rígido, tratamento de erros centralizado e validações de domínio (como formato de CPF, e-mail, idade mínima e piso salarial).

Biblioteca municipal

Um sistema desenvolvido em Node.js utilizando Módulos ES ( import/ export) para o gerenciamento de leitores, cadastro de itens (livros físicos e e-books) e cálculo de multas por atraso. O projeto aplica conceitos fundamentais de Programação Orientada a Objetos (POO) como encapsulamento, herança, polimorfismo e classes abstratas.
